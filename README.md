# MMShell

MMShell 是一个基于 `Tauri + Rust` 的新一代终端与远程运维客户端，目标是达到并超越同类主流产品的体验与稳定性。



- 目前实现的功能 基本的ssh  保存会话，文件拖拽功能
- 增加了右侧快捷命令栏的功能,对于初学者友好，反复输入繁琐命令友好
